### [Rubriqly](https://github.com/ahmastan/rubriqly)
Rubric-based essay feedback for students. Estimates a level for each rubric criterion, tags every paragraph for claim, evidence, and analysis, and tracks progress across drafts. A self-check tool, not a grader: it never writes text for you.

- Scores drafts for under **$0.0004 per check**
- Scores up to **60 paragraphs in parallel** with TypeSafe's Jev model via Vercel AI Gateway
- Usage limits of 30 checks per user and 500 per day site-wide keep a free-tier deployment within budget

`React` `TypeScript` `FastAPI` `PostgreSQL` `Neon` `Render`

### [Zephdeck](https://github.com/zephydian/zephdeck)
A free, open-source macOS menu bar utility and game panel. Hover over a screen corner and a panel appears with tabbed Markdown notes, utilities, and games.

- Runs in about **25 MB of memory**, idling at about **0.1% CPU**
- Sandboxed, zero-network design with no accounts or tracking
- Distributed via Homebrew and a live browser demo, supporting macOS 14+ on Apple Silicon and Intel

`Swift` `SwiftUI` `XcodeGen` `Homebrew`

**[Try it in your browser](https://zephydian.com)** · **[Source](https://github.com/zephydin/zephdeck)** · **[Releases](https://github.com/zephydian/zephdeck/releases)**
